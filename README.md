# React Ludo Game 🎲

A real-time multiplayer Ludo game built with React, Vite, and Firebase Realtime Database.

## Features
* **Real-time Synchronization:** Multiple players can track turns and piece positions across the browser.
* **Turn-based gameplay:** Cycles automatically through Red, Green, Yellow, and Blue.
* **Firebase Backend:** Reads and writes state in real-time.

## Prerequisites

Before running this project, make sure you have:
* Node.js installed on your computer (if running locally).
* A Firebase account and project.
